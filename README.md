# MemoryDesk

### AI Customer Support with Persistent Memory

**Built by Chaos & Co. for Hack With Hyderabad 3.0**

MemoryDesk is an AI-powered customer support agent that uses Hindsight persistent memory to remember previous customer interactions, troubleshooting steps, and outcomes.

Instead of making customers repeat their problems, MemoryDesk recalls relevant history and provides more contextual support during future interactions.

## How It Works

Customer Message
→ AI Support Agent
→ Hindsight Memory
→ Recall Previous Context
→ Contextual Response

## Key Features

- AI-powered customer support
- Persistent customer memory using Hindsight
- Recall of previous troubleshooting history
- Context-aware responses
- Simple chat-based interface
- Visible memory panel

## Technology

- React
- Vite
- Node.js
- Express
- Hindsight
- Hindsight Client
- JavaScript

## Demo

Example:

First interaction:
"My Wi-Fi keeps disconnecting on my Dell laptop. I already restarted the router."

Later:
"It is happening again. What did we try last time?"

MemoryDesk recalls the previous interaction and responds using that context.
